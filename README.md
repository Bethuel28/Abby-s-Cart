# Abby's Cart

Personal grocery list app: saved item catalog, one-tap add, per-line prices, budget with
suggested cuts, brand price comparison, light/dark mode. Offline, no account.

## Get the APK

1. Push this folder to a GitHub repo (branch `main`).
2. Open the **Actions** tab, run **Build APK** (it also runs on every push).
3. When it finishes, download the `abbys-cart-apk` artifact, unzip it and install `app-debug.apk` on the phone
   (allow "install unknown apps" when asked).

## Edit the app

Everything lives in `www/index.html`. The icon sources are in `assets/`.
